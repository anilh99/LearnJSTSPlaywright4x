Why does a.status become "Fail"?

Because a and b refer to the same object. Assigning one object variable to another copies the reference, not the object.

let a = { status: "Pass" };
let b = a;
b.status = "Fail";
console.log(a.status);

The assignment b = a makes b hold the same object reference as a. So changing the object's status through b is visible when reading it through a.

Run it one line at a time

  1. a refers to an object whose status is "Pass".
  2. b = a copies the reference, so a and b point to that same object.
  3. b.status = "Fail" changes the shared object's property.
  4. a.status reads that changed property. The console prints Fail.

Want a separate object?

Make a shallow copy with object spread before changing it:

let a = { status: "Pass" };
let b = { ...a };
b.status = "Fail";
console.log(a.status); // Pass
console.log(b.status); // Fail

Object spread makes a new outer object. It is a shallow copy: if the object contains nested objects, those nested values are still shared unless copied separately.
